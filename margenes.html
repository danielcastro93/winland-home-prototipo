Un solo margen lateral de 16 px

Medido en las páginas reales del sitio a 390 px de ancho. Hoy cada sección deja un margen distinto (de 14 a 46 px). Con una regla para celular todas quedan a 16 px. En escritorio no cambia nada.

Deportes

46 px → 16 px

El sportsbook de Altenar va envuelto en dos contenedores de Calimaco (14 + 32 px). Se quita el de 32 px.

Promociones

30 px → 16 px

Dos rellenos encimados (14 + 16 px). Se deja uno solo de 16 px.

Casino

14 px → 16 px

Las cards pasan de 14 a 16 px y los títulos de cada fila, de 22 a 16 px, alineados con las cards.

Casino en vivo

14 px → 16 px

Igual que Casino: mismo contenedor y mismas filas.

Home (staging)

28 px → 16 px

Se quita el margen de 12 px del contenedor; cada bloque ya trae sus 16 px.

Reglas para Calimaco

El ajuste es de Calimaco, no de Altenar: el contenido de Altenar arranca justo en la orilla de su contenedor. Son cinco contenedores de página; no hace falta rediseñar nada.

/* Margen lateral único de 16 px en celular (hasta 899 px de ancho) */
@media (max-width: 899px) {
  /* Casino, Casino en vivo, Promociones y Deportes: 14 → 16 px */
  .clmc-casino-lobby { padding-left: 16px; padding-right: 16px; }
  /* Deportes: quitar los 32 px extra alrededor del sportsbook */
  .clmc-p-large:has(> .clmc-altenar-widget-shell) { padding-left: 0; padding-right: 0; }
  /* Promociones: quitar el segundo relleno de 16 px */
  .clmc-promociones-container { padding-left: 0; padding-right: 0; }
  /* Títulos de las filas del casino: alineados con las cards */
  .clmc-casino-lobby .clmc-justify-between.clmc-align-baseline { margin-left: 0; }
  /* Home: contenedor sin margen extra y encabezado de tragamonedas alineado */
  .wl-home-shell { padding-left: 0; padding-right: 0; }
  .wl-slotgal__head { padding-left: 16px; padding-right: 16px; }
}

Cómo verlo tú en el navegador

  1. Abre en Chrome de tu computadora la sección que quieras revisar (por ejemplo winland.com.mx/deportes).
  2. Clic derecho en la página → Inspeccionar (o Cmd + Opción + I).
  3. Activa la vista de celular con el ícono de teléfono y tableta arriba a la izquierda del panel (o Cmd + Shift + M) y elige un iPhone de la lista.
  4. Ve a la pestaña Console, pega el código con el botón de arriba y presiona Enter.
  5. El cambio se ve al instante. Al recargar la página vuelve a como estaba: no se toca el sitio.
